# Test checklist

1. Start without external assets and confirm no parser errors.
2. Press F10 and inspect the asset-status overlay.
3. Add a non-rigged character and confirm the skeleton warning.
4. Add a rigged character and inspect animation/socket validation.
5. Add an environment asset without collision and inspect the warning.
6. Confirm generated collision status appears.
7. Move far from imported models and observe shadow/visibility LOD.
8. Confirm procedural fallbacks remain when imports fail.
9. Confirm bots, scoreboard, tactical map and objectives remain.
10. Confirm v7.3.0 protocol 341.
