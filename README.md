# Frontline: Objective

## Version 2.2.0 combined gameplay expansion

This larger milestone combines several systems.

### Combat
- Headshot detection using server-authoritative hit height
- 1.75x headshot damage
- Separate HEADSHOT confirmation
- Networked bullet tracers
- World-space impact flashes
- Bot tracers and occasional bot headshots
- Bots can throw grenades at medium range

### Objectives and HUD
- Persistent objective progress bar
- Construction, defuse, and bunker-damage modes
- Cleaner connection/version line
- Removed temporary input-ack and position diagnostics
- Improved scoreboard with team, class, kills, deaths, XP, rank, actor type, and state
- Larger scoreboard layout

### Downed and revive flow
- Downed human players remain visible
- Friendly downed players show a REVIVE marker
- Bots still die immediately and respawn on waves

### Round flow
- Full round-end results panel
- Final scoreboard shown between rounds
- Automatic hide when the next round starts

### Map and bots
- Added side-lane cover
- Added raised combat platforms
- Added center-route cover
- Improved combat route variety
- Bots use grenades situationally

Install the same package on Windows and Linux.
