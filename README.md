# Frontline: Objective

## Version 8.12.0 — Objective Setpiece Fidelity

Enemy Territory-style objectives are now visually identifiable battlefield set pieces. Bridge construction reveals staged planks and structural pieces as engineers make progress. The command post gains a field table, detailed radio, controls, frequency display, antenna, and map board. The supply depot gains a canvas canopy, detailed crates, bands, poles, and artillery stores. Dynamite is represented by a complete wired bundle and timer, while the bunker receives a roof slab, blast door, firing ports, and vents. Sector ownership is reinforced by physical field flags that change color with control and contention.

All additions are decorative and client-side. Existing objective logic, interaction radii, collision, navigation, server authority, and protocol 341 remain unchanged.
