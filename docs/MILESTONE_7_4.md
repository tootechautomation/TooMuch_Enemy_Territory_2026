# Test checklist

1. Start the client and enter a custom name on the connection screen.
2. Join the server and confirm the scoreboard shows the custom name.
3. Confirm kill-feed and downed messages use the custom name.
4. Press F8, change the name, save and confirm the server updates it.
5. Restart the client and confirm the name remains.
6. Change sensitivity and verify mouse movement changes immediately.
7. Change FOV and HUD scale.
8. Change preferred team/class and reopen the spawn menu.
9. Connect to another compatible server and confirm the same profile is used.
10. Confirm v7.4.0 protocol 341.
