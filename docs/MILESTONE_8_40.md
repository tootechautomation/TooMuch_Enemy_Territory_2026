# Milestone 8.40 — Team-Specific Historical Asset Integration

This milestone prepares Frontline: Objective for the seven user-selected CGTrader assets. Team-specific weapon/pistol resolution replaces the prior shared service-pistol path, requested character names are highest-priority candidates, and the Axis grenade can display the Model 24 external mesh.
