# Test checklist

1. Start the round and confirm both field guns show OFFLINE.
2. Build the bridge and capture the command post.
3. Confirm both guns activate for the controlling team.
4. Approach as an enemy and confirm the guns acquire and fire.
5. Deploy smoke and confirm guns stop firing through it.
6. Shoot each destructible cover position and observe three damage states.
7. Destroy cover and confirm collision disappears.
8. Start a new round and confirm destroyed cover is restored.
9. Observe bots using different north, south and center routes.
10. Confirm the operations HUD displays command-post gun ownership.
